#### **A Fixed Supply, Closed Early:**

NGIT was originally designed with a maximum supply of 5,000,000 tokens, issued over a five-year window running from February 2022 to January 2027.



That window closed early. With the migration to Immutable zkEVM, issuance was permanently ended at **3,558,651.991 NGIT** — approximately 71% of the original cap. The remaining \~1.44 million tokens were never minted and never will be.

|                         | Tokens        | Share of original cap |
| ----------------------- | ------------- | --------------------- |
| Original maximum supply | 5,000,000     | 100%                  |
| Actually issued (final) | 3,558,651.991 | 71.2%                 |
| Permanently unissued    | 1,441,348.009 | 28.8%                 |

{% hint style="info" %}
**What this means for holders.** Governance weight in Sheepfarm cannot be diluted. There is no emission schedule, no treasury unlock, and no future mint function that can reduce the relative weight of an existing NGIT balance.
{% endhint %}

#### **Markets & Liquidity:**

NGIT trades on **QuickSwap** on Immutable zkEVM.

| Pool        | Composition                                                                                                             |
| ----------- | ----------------------------------------------------------------------------------------------------------------------- |
| NGIT / USDC | 990,100 NGIT : 712.9 USDC — price discovery pair                                                                        |
| NGIT / MARD | 999,259 NGIT : 999,038 MARD — governance pair, 1% fee tier. **A full-range LP position here is required to earn vNGIT** |

Both pools use concentrated liquidity, and positions are issued as **liquidity provider NFTs** rather than fungible LP tokens. Only full-range positions in the NGIT–MARD pool qualify for vNGIT — see the vNGIT page.

{% hint style="info" %}
Liquidity in these pools is limited, and prices can move sharply on small trades. Providing liquidity exposes you to impermanent loss. Trade and provide at your own discretion.
{% endhint %}
